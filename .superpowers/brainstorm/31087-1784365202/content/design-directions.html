Flameshot UI — Apple-inspired Redesign

Thinking like Steve Jobs & Jony Ive. The UI works great but the polish is where Apple would obsess.

Current Pain Points

Default Purple Theme

Current default #740096 is harsh — feels like a 90s Linux app. The two-color system (uiColor + contrastUiColor) is inflexible for modern design.

Flat Single-Color Buttons

Circular buttons work well but the flat fill + drop shadow feels dated. No gradients, no subtle borders, no material depth.

Unthemed Side Panel

Side panel and utility panel use system palette — completely disconnected from the capture UI theme. Looks like two different apps.

Flat Dark Overlay

Inactive region is just solid black at 75% opacity. Apple would use translucency/vibrancy or at minimum a more sophisticated treatment.

Three Design Directions

A

Refined Current

Better default colors, softer opacity handling, subtle border-radius on corners, improved panel styling. Low effort, big impact.

B

macOS Inspired

Frosted-glass translucency for overlay, gradient buttons with inner shadow, thin vibrant selection borders, unified panel theme. Medium effort.

C

Complete Overhaul

Extend theme to 4+ colors (bg, surface, accent, text), add QSS support, spring animations, adaptive light/dark mode, refined typography. High effort.
